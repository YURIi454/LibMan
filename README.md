## Проект LibMan
###### Library Manager
## API для управления библиотекой
### Реализованный функционал
  * Управление книгами (CRUD)
  * Управление авторами (CRUD)
  * Управление пользователями (CRUD)
  * Управление выдачей книг (CRUD)


### В проекте используется
* Django 
* Django DRF
* PosgreSQL
* Docker
* Docker Compose
* Документация API

### Структура проекта
* authors - управления авторами
* book_loan - управления выдачей книг
* library - основное управления книгами
* users - управление пользователями

### Установка и запуск
* склонировать репозиторий по [ссылке](https://github.com/YURIi454/LibMan.git)
* заполнить файл .env, переменные указаны в файле .env.deploy
* применить миграции
* локальный запуск командой __python manage.py runserver__
